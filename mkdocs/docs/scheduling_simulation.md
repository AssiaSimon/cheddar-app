# 1. Basic Features: Scheduling Simulation
This chapter provides an overview of how to use the Cheddar Web application 
for scheduling simulations.

## 1.1 Step One: Fetch XML Files
This section explains how to import XML files generated by the Cheddar software.

To begin, enter the URLs of both the **System Model** and the **Event Table** 
XML files into the corresponding fields.

![add_URL](img/add_URL.png)

*Figure 1.1.1: Adding URLs of XML files*

##### Accessing Example URLs
Three example URLs are available through the buttons **Ex1**, **Ex2**, and 
**Ex3**. Clicking on any of these buttons will dynamically fetch the URL 
associated with the selected example.

![fetch_exo2_URLs](img/fetch_exo2_URLs.png)

*Figure 1.1.2: Fetching the URL for Example 2*


## 1.2 Step Two: Choose the Time Unit for Simulation Display
This section explains how to configure the time range for displaying the 
scheduling simulation.

In the **Draw upto** field, enter the maximum time unit you want the simulation 
to be displayed up to.

![choose_time](img/choose_time.png)

*Figure 1.2.1: Entering the time limit for simulation display*

> **Note**: if the time you enter exceeds the maximum time unit available in the 
>**Event Table** generated by Cheddar, the application will automatically adjust 
>it to the allowed maximum and display a message indicating the corrected value.

![message_displayed_mxTime](img/message_displayed_mxTime.png)

*Figure 1.2.2: Message indicating the maximum allowable time unit*


## 1.3 Step Three: Run the Simulation
This section guides you through launching the simulation.

After entering the URLs of the required XML files and setting the simulation time, 
click the **Simulate** button.

The simulation will then appear below the form.

![simulation_display](img/simulation_display.png)

*Figure 1.3.1:  Display of the simulation*

> **Note**: If the simulation output extends beyond the visible area, you can scroll 
>vertically and horizontally to view the full schedule.

#####Table Display of Simulation Parameters
A table will appear below the simulation to display key parameters for each task:

- Task Name
- Task Type
- Task Period
- Task Capacity
- Task Deadline
- Processor Name
- Assigned Color

![table_display](img/table_display.png)

*Figure 1.3.2:  Table Display of Task Information*


## 1.4 Personalizing the Simulation Display
This section explains how you can personalize the simulation display according to your preferences.

##### 1.4.1 Adjusting the Simulation Size
You can adjust the size of the simulation display using the **+** and **-** buttons. 
These buttons allow you to zoom in and out of the simulation.

![adjust_size](img/adjust_size.png)

*Figure 1.4.1: Adjusting Simulation Size with Zoom Buttons*


##### 1.4.2 Customizing Task Colors
To personalize the colors of the tasks, simply click on the color picker assigned 
to the relevant task in the information table below the simulation. A color palette 
will appear, enabling you to choose your preferred color. 

![change_task_color](img/change_task_color.png)

*Figure 1.4.2.1: Changing the Color of a Task*

You can also adjust the color of the period boundary of a task or the start and 
end delimitations for shared resource access. The corresponding color pickers 
are located below the simulation.

![change_color](img/change_color.png)

*Figure 1.4.2.2: Adjusting Task Delimitations and Resource Access Colors*
