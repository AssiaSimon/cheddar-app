# 2. Generating a System Model 
This chapter provides an overview of how to use the Cheddar Web application to 
generate a system model that can be imported into the Cheddar software.

## 2.1 Adding and Removing Tasks

##### Adding a Task

To add a new task, click the **Add Task** button. A form will appear, allowing 
you to enter the required data for the task.

![adding_task](img/adding_task.png)

*Figure 2.1: Task Addition Form*

> **Note**: The task name must not contain spaces; an error message will appear 
> if this rule is violated. Additionally, the Period, Deadline, and Capacity 
> parameters must be numeric.


##### Removing a Task

To remove a task, simply click the **Remove Task** button.


## 2.2 Saving the System Model

To save the system model with the parameters you’ve defined, click the ** Save Model** 
button. A confirmation message will display, indicating the number of tasks 
currently saved in the model.
 
![save_model](img/save_model.png)

*Figure 2.2: Saving the System Model with Selected Parameters*


## 2.3 Generating the System Model

To generate the saved system model, click the **Generate** button. A download 
link will appear, allowing you to download the system model file.

![download_system](img/download_system.png)

*Figure 2.3: Download Link for the System Model*
