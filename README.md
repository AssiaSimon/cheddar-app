# Cheddar App : Application web de visualisation de l’ordonnancement temps réel

## Objectif 

Développement d’une application web permettant de visualiser graphiquement la simulation de l’ordonnancement des tâches dans les systèmes temps réel modélisés avec Cheddar. Le projet vise à proposer une alternative aux limitations de compatibilité entre Cheddar et certains systèmes d’exploitation, en permettant d’exploiter et de visualiser les simulations directement depuis une interface web.

## Technologies et compétences

    - Frontend : HTML, CSS, JavaScript
    - Données : XML
    - Systèmes : systèmes temps réel, modèles de tâches
    - Algorithmique : algorithmes d’ordonnancement des tâches
    - Documentation : MkDocs
    - Gestion de versions : Git / GitLab

## Fonctionnalités principales

    - Visualisation graphique de l’ordonnancement des tâches
    - Exploitation de modèles de systèmes temps réel
    - Représentation des résultats de simulation sous forme graphique
    - Traitement de données au format XML
    - Documentation technique du projet avec MkDocs
    - Interface web indépendante des contraintes de compatibilité du logiciel Cheddar
